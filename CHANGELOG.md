# Changelog

All notable changes to Verdic Skills will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- `application-security-review` skill (auth, secrets, injection, XSS, supply chain).
- `api-http-testing` skill (unit/integration/contract pyramid for APIs).
- `observability-logging` skill (structured logs, correlation, safe diagnostics).

### Changed

- Renamed repository from `maurao-skills` to `verdic-skills`.
- Repositioned as Verdicspec skill library (not CleanStack companion).
- Clarified adaptation notes and related links on existing skills.

## [0.1.0] - 2026-07-11

### Added

- .NET backend Clean Architecture skill.
- Angular frontend Clean Architecture skill.
- React and Next.js Clean Architecture skill.
- Automated skill structure validation.
- CI workflow for skill validation.
- Repository governance and contribution templates.
